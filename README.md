# BookKG — сайт поиска книг в Бишкеке

Проект на Next.js + Supabase. Включены адаптивный каталог, поиск по названию/автору/ISBN, русский/кыргызский переключатель, избранное в браузере, WhatsApp-связь с магазином, вход администратора, добавление магазинов и импорт CSV.

## Подключение базы
1. В Supabase откройте SQL Editor → New query.
2. Вставьте весь файл `supabase/schema.sql` и нажмите Run.
3. В Supabase Authentication → Users создайте пользователя с email и паролем.
4. Скопируйте UUID пользователя. В SQL Editor выполните, подставив UUID:
   `insert into public.user_profiles(id,role) values ('ВАШ_UUID','admin') on conflict(id) do update set role='admin';`
5. В Project Settings → API скопируйте Project URL и publishable key (или anon key). Не используйте service_role key в браузере.

## Публикация в Vercel
1. Загрузите содержимое этой папки в новый GitHub repository. Не загружайте `.env.local` и секретные ключи.
2. На Vercel выберите Add New → Project и импортируйте репозиторий.
3. В Environment Variables добавьте `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
4. Нажмите Deploy. После публикации откройте выданный Vercel URL.

## CSV
Одна строка = одно предложение книги в выбранном магазине. Колонки: `title,author,isbn,price,available`. Также понимает заголовки `Название`, `Название книги`, `Автор`, `ISBN`, `Цена`, `В наличии`. Импорт по ISBN обновляет существующую книгу; без ISBN ищет по названию. Проверяйте дубликаты.

## Важно
Это стартовая рабочая версия, но не полный коммерческий сервис. В ней пока нет SMS-входа по телефону, загрузки Excel XLSX (есть CSV), самостоятельной регистрации магазинов, модерации заявок и автоматического подключения к кассовым системам. Для подключения внутренней базы магазина требуется его разрешённый экспорт или API. Перед открытием для всех пользователей нужны тестирование, резервное копирование и настройка домена.


## Дополнительные возможности этой сборки
- Магазин может подать заявку: `/register-store`.
- После подтверждения номера по SMS администратор рассматривает заявку: `/admin/applications`.
- Одобренный магазин получает кабинет `/store`.
- В кабинете магазина можно загружать `.xlsx`, `.xls` и `.csv`; импорт меняет только предложения этого магазина.
- Для SMS обязательно включить Phone provider в Supabase Authentication и подключить SMS-провайдера (например, Twilio) с его собственными учётными данными и разрешённым отправителем. Без этих внешних настроек SMS не отправятся.
- Администратор после запуска SQL должен создать auth-пользователя и назначить ему роль `admin` как описано выше.
- После импорта проверьте соответствие колонок своего Excel-файла. Разные кассовые программы используют разные форматы; универсального безопасного подключения к их внутренней базе нет.
- В этой версии заявка магазина и подтверждение номера реализованы, но автоматическое SMS-провижининг/оплата SMS, проверка прав владения бизнесом, массовая синхронизация POS API, уведомления и полноценное редактирование каталога через UI требуют внешних настроек и дальнейшего тестирования.
